# Life and Origins

**Status:** original browser alchemy and discovery game  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

Life and Origins is a browser combination game where players place elements into a workspace, drag them together and discover new results through successful combinations.

## Gameplay

- select elements from the library
- place them in the workspace
- drag two elements together
- discover a resulting element or life form
- continue combining discoveries to expand the available set

The current project also experiments with generated visual representations for discoveries when the configured image service is available.

## Technology

React, browser drag interaction, Tailwind CSS, Web Audio and mobile haptic feedback.

## Scope

Life and Origins is a game project. Generated imagery is a presentation layer and should not be interpreted as scientific evidence about biological origins.

Existing branches and historical files are retained as development history.
